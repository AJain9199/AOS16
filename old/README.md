# AOS16 - Old Files

This folder contains files, schematics and PCB designs which never made it into the final project. It includes poorly designed boards and old simulation files. This is maintained as an archive. 

| File/Folder | Purpose |
| ----------- | ------- |
| AOS16 Register | Old register design. An entire board, dedicated to one 16-bit register. Nightmare to fabricate and wasteful. Ditched for newer reg4x16 design which uses register files. |
| AOS16 Timer | The very first PCB I ever made. A copy of Ben Eater's clock circuit. I waster 10 of these boards before I learned how to actually solder using a hot air gun. Learned DRC the hard way. Straight up forgot 2 traces, had to make skip connections. |
| schematic.circ | Old simulation files for logisim. Migrated to Hneeman's Digital for VGA display sim. |
